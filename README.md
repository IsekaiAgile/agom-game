# アガイルド〜炎の王国〜

**AGOM (Agairud Game Of Management)**

過労で倒れたITエンジニアが、異世界「アガイルド」で「アジャイルな働き方」を学び直すファンタジーRPG。

---

## 🎮 ゲーム概要

### ストーリー
ITエンジニアの藤田雄真（ふじた ゆうま）は、過労で意識を失う。目覚めるとそこは謎の空間「転生の間」。試練を乗り越えた先で、竜のアジャドラが現れ、異世界「アガイルド」への転生を導かれる。

炎の王国アガイルドで、彼は本当の「働き方」と「生き方」を学んでいく――。

### テーマ
- 過労社会への警鐘
- アジャイルな働き方の学び
- 自分を大切にすることの重要性
- チームワークと成長

## 🚀 現在の実装状況

### ✅ 完成
- **ロゴシーン**: 「異世界アジャイル」制作会社ロゴ
- **オープニング動画**: オープニングムービー（スキップ対応、opening-theme BGM）
- **プロローグシーン**: 完全なシナリオ（選択肢システム付き）
- **エリギアタイトル**: 異世界エリギアへの導入
- **暗転シーン**: トンネル演出
- **レイグアシーン**: 異世界レイグアでのストーリー
- **追いかけゲーム**: チェイスシーン
- **転生の間**: 横スクロールアクションゲーム
  - パララックス背景
  - BGM & 光のエフェクト
  - プレイヤー、敵、ゴール
- **アジャドラシーン**: アジャドラとの出会い
- **扉選択・職業確定**: 職業選択フロー
- **オワリの街**: 町シーン
- **BGMシステム**: シーンごとの音楽切り替え
- **デバッグメニュー**: Dキーで各シーンに即座に移動可能

### 🔄 実装中・予定

## 🎬 プレイ方法

### オンラインプレイ
https://isekaiagile.github.io/agom-game/

### ローカル実行
```bash
# インストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build

# プレビュー
npm run preview
```

- **Dキー**: デバッグメニューを開く

## 🎨 アセット

### BGM
- `dark-bgm.mp3`: プロローグ（暗い雰囲気）
- `fantasy-bgm.mp3`: タイトル、アジャドラシーン（ファンタジー）
- `opening-theme.mp3`: オープニング動画
- `trial-bgm.mp3`: 転生の間（神秘的）

### 動画
- `opening.mp4`: オープニングムービー

### 背景画像
- 現実世界: 部屋、電車、オフィス
- 異世界: アガイルド、転生の間
- ロゴ: isekai-agile-logo.png, agom-title-logo.png

## 🎮 操作方法

### キーボード
- **矢印キー（← →）**: 移動
- **スペースキー**: ジャンプ
- **クリック**: テキスト送り・選択肢・スタート
- **Dキー**: デバッグメニュー

### タッチ操作（モバイル）
- **画面左1/3**: 左移動
- **画面右1/3**: 右移動
- **画面中央上部**: ジャンプ
